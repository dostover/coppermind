The core inversion

Traditional cards

Value = scarcity + resale + “will it appreciate?”

Banana Cards

Value = what you experienced + who you shared it with

Scarcity can exist. It’s never the measure, and the product never creates or rewards it.

Banana Cards · 3

This is the whole thesis on one slide. Traditional value is scarcity, resale and speculation. Banana Cards inverts it: value is the experience of getting the card and the people you shared it with. Note the principle: we don’t try to police a resale market, because anything tradeable can be priced somewhere. We make sure the product never manufactures scarcity. If cards start selling for real money, that’s a signal the design let scarcity creep in.
