# Banana Cards

Notes for the digital trading card system and portal for Banana Ball.

The app itself lives at `../../apps/banana-cards/`. This folder is where
requirements, architecture, and design notes land as the project takes shape.

- [card-value-model.md](card-value-model.md) — why the cards work the way they
  do: value from presence, story and trading instead of scarcity, the
  redemption/ownership/trade decisions, and the Fan First proposals.
- [technical-decisions.md](technical-decisions.md) — engineering decisions
  (API-first, auth, demo-phase shortcuts) and the "before real fans" list.
- [01-data-model.md](01-data-model.md) — entities and relationships for the
  card/redemption/trade system, grounded in the value-model decisions above.

The first two are copies of docs kept in the Banana Cards Claude project
(`claude/card-value-model.md` and `claude/technical-decisions.md`), where
they're usually edited first.
