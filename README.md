# coppermind

## Structure

- `coppermind/` — code
- `apps/` — apps: Inkwell, Banana Cards, [Rondolette](apps/rondolette/) (an online multiplayer spinning-top board game, [play it](https://daniels-rondolette-app.netlify.app/)), [Tavern Dice](apps/tavern-dice/) (a collectible-dice minigame for a D&D campaign, with a table app and balance simulator), and [Pixel Party Dungeon](apps/pixel-party-dungeon/) (a couch co-op dungeon crawler for kids that mixes Spelunky platforming with Baldur's Gate 3-style dice battles)
- `docs/` — notes and written content
